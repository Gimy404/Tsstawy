## 1. الفكرة العامة للمشروع وببساطة

المشروع ده عبارة عن **معرض أعمال وموقع خدمات تسويق رقمي ثابت (Static Portfolio Website)**. 
الموقع معمول عشان يعرض خدماتك وخبراتك للعملاء وأصحاب الشركات في مصر والخليج، ويسمح لهم يتعرفوا على سابقة أعمالك ويتواصلوا معاك مباشرة وبأسهل طريقة.

## 3. مكونات المشروع ودور كل جزء

1. **الصفحة الرئيسية (`index.html`):**
   - واجهة الدخول الأولى للعميل.
   - تحتوي على هيدر ترحيبي باسمك، نبذة عن خبرتك (About Me)، كروت مختصرة لكل خدمة تقدمها مع زر يفتح صفحتها التفصيلية، معرض سابقة أعمالك (Portfolio)، وقسم التواصل.
2. **صفحات الخدمات الفرعية (Subpages):**
   - سبع صفحات متخصصة، كل صفحة تشرح تفاصيل خدمة معينة ومزاياها للعميل مع أمثلة عملية.
3. **ملف التنسيقات المخصصة (`styles.css`):**
   - الملف ده بيتحكم في اللمسات الخاصة بالموقع: حركة التمرير الناعمة، وتأثيرات أزرار الواتساب، وتناسق الخطوط على شاشات الموبايل.
4. **ملفات التنسيق والمكتبات المحلية (`muradmurad.com/`):**
   - تم حفظ كافة ملفات الـ CSS والـ JS والصور والخطوط محلياً داخل المشروع حتى لا يعتمد الموقع على أي سيرفر خارجي، مما يجعله سريعاً جداً ومستقراً 100%.
5. **ملفات السيو والأرشفة (`sitemap.xml` و `robots.txt`):**
   - ملفات بتعطي إشارات لمحركات البحث (جوجل وبينج) عشان تفهرس موقعك وتظهر كل صفحات الخدمات في نتائج البحث باسمك.

## 4. إزاي التعديل بيحصل لما تحب تغير حاجة؟

* **عايز تغير رقم الواتساب أو الإيميل؟**
  - تفتح ملف `index.html` وتبحث عن `wa.me/201098726800` وتغيره لرقمك الجديد، ونفس الشيء للإيميل.
* **عايز تضيف أو تعدل خدمة؟**
  - كل خدمة لها ملف HTML مستقل بذاتها، تقدر تعدل النصوص المكتوبة داخله مباشرة.
* **إزاي التغييرات تظهر على النت؟**
  - مجرد ما تعمل `git commit` وترفعها على فرع `main`، منصة GitHub Pages بتحدث الموقع أوتوماتيكياً في خلال دقيقة واحدة بدون أي تدخل يدوي منك!

## 💻 How to Run Locally (طريقة التشغيل محلياً)

Because this is a completely static website, you do not need Node.js, databases, or build servers.

### Option 1: Direct File Opening
Double-click on `index.html` in your file explorer to open it in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python (if installed):
```bash
python -m http.server 8080
```
Or using Node.js:
```bash
npx serve .
```
Then visit `http://localhost:8080` in your browser.
